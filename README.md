# StudyHub Web Application

StudyHub is a simple academic web application for students, lecturers, and administrators.

## Features
- Student dashboard
- Course list
- Assignment submission
- Grades view
- Announcements
- Admin dashboard
- Submission approval and rejection workflow
- SQLite-backed submission tracking
